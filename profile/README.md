The JayOS is not OS from scratch project but is made by configuring archios which is a lot less impressive. We would like it to be from scratch so we can larp but its currently outside of our knowledge and time range, as our main developer is more focusing on IT career than the programming one. It is source code of the [jaylub.com](https://jaylub.com) which is also bought by us and hosted by cloudflared tunnel.
